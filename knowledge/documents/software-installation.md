## Symptoms
- The user needs an application that is not installed on their device.
- An installation from the Software Center fails or stays at "Pending".
- The user receives a message that administrator permission is needed.
- The user asks to install software from the internet.

## Common Causes
- The application is not part of the standard software set for the user's role.
- The device has not checked in with device management recently, so installs stay pending.
- Not enough free disk space.
- The software is not approved for company use.

## Troubleshooting Steps
1. Check whether the application is listed in the Software Center. Approved applications can be installed there by the user without administrator rights.
2. If it is listed, ask the user to install it from the Software Center and keep the device connected to the network until the installation finishes.
3. If an installation stays pending or fails, restart the device, check that there is enough free disk space, and try again.
4. If the application is not in the Software Center, ask the user for the name of the application, the reason they need it, and their manager's approval. Create a software request ticket with this information.
5. Explain that software outside the approved catalog goes through a review by IT Support and Security. This can take some time, and approval is not guaranteed.

## Restricted Actions
- Do not install software from unofficial sources, or ask the user to download installers from the internet.
- Do not give a user local administrator rights, and do not disable device management or security tools to make an installation work.
- Do not install or approve software licences without an approved request.

## When to Escalate
Escalate to IT Support if a catalog application fails to install after the steps above.

Escalate to Access Management if the user needs elevated permissions for approved software.

Escalate to Security if the requested software is unapproved, unknown, or the user says an installer arrived by email or message.
